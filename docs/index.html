$ ~/task-manager/login
メールアドレスとパスワードでログインしてください。どの端末からでも同じアカウントでログインすれば、同じタスクにアクセスできます。
アカウントをお持ちでない場合は 新規登録
$ ~/task-manager -- EDIT MODE (Esc でキャンセル)
usage: <タスク名...> [-t <タグ>] [-d <YYYYMMDD>] [-h <HHMM>] [所要時間h] example: ミーティング会議 -t 会議 -d 20260903 -h 1000 0.5 省略時デフォルト: タグ=なし / 日付=当日 / 時刻=現在時刻 / 所要時間=0 keys: ↑↓ 選択移動 ←→ ペイン切替 Enter 編集 Delete 削除 a アーカイブ切替 / 検索 Esc 入力欄を離れる/編集キャンセル/検索解除 編集中はメモ欄が使用できます (Ctrl+Enter で保存) テキストスパンディング: 例) ;todo と入力すると [ ] に自動展開(snippetsボタンで作成・編集、複数行の展開文字列にも対応)
$
# memo
/
#
空白の直後にトリガー文字列を入力すると、展開文字列(複数行可)に自動で置き換わります。
# 新規作成
# pending_tasks (0)
# archived_tasks (0)
